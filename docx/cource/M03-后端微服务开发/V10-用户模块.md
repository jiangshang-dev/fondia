# V10 用户模块 jeecg-user：邮箱与华为登录

> **所属模块**：M3  ·  **建议时长**：50～70 分钟  ·  **形式**：讲解 + Postman
> **对应大纲**：`Fondia_全栈实战课程大纲.md` → 3.2

## 一、学习目标

1. 读懂 LoginController 登录链路
2. 调通邮箱登录与 profile
3. 理解华为 OAuth 换 token 流程

## 二、课前准备

- user 服务已启动
- 准备 Postman 集合

## 三、口播 / 讲解提纲

### 3.1 邮箱登录

- 验证码发送与校验
- 密码登录可选
- JWT 签发与返回结构

### 3.2 华为登录

- POST /user/auth/huaweiLogin
- 服务端用 authorizationCode 换用户信息
- client_id 与 App metadata 必须一致

### 3.3 资料接口

- Authorization 头
- Feign 供其他服务解析用户

## 四、屏幕演示步骤

1. 走读 emailLogin → FdUserServiceImpl
2. 走读 huaweiLogin → HuaweiOAuthClient
3. Postman：登录拿 Token → GET /user/profile

## 五、课堂实验 / 作业

1. Postman 调通邮箱登录与 GET /user/profile
2. 画出华为登录时序图（App → 后端 → 华为）

## 六、本节小结（片尾 1 分钟）

- Token 由后端签发，客户端只存不造
- 华为 Secret 绝不能下发 App
