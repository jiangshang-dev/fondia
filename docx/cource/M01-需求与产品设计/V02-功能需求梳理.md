# V02 功能需求梳理（C 端 / 登录 / 后台 / 后端）

> **所属模块**：M1  ·  **建议时长**：30～40 分钟  ·  **形式**：讲解 + 表格拆解
> **对应大纲**：`Fondia_全栈实战课程大纲.md` → 1.2

## 一、学习目标

1. 按端列出核心功能清单
2. 能将功能映射到后续微服务模块
3. 阅读需求说明书并补充差异化点

## 二、课前准备

- 打开大纲 1.2 功能表
- 打开需求说明书

## 三、口播 / 讲解提纲

### 3.1 C 端 App

- 首页 Banner/推荐
- 分类与详情
- 搜索
- 收藏/点赞/评论
- AI 专属厨伴
- 我的（积分/VIP/设置）

### 3.2 登录

- 邮箱验证码、密码登录
- 华为账号登录（鸿蒙 LoginType.ID）
- Token 持久化与协议勾选

### 3.3 管理后台

- 菜谱/分类/标签/Banner
- 用户/反馈/看板
- AI 客服配置
- 会员与配额

### 3.4 后端

- 微服务 API、网关路由、文件上传、支付回调

## 四、屏幕演示步骤

1. 对照大纲表格逐行讲解
2. 在白板上画出「功能 → 模块」箭头

## 五、课堂实验 / 作业

1. 阅读 `Fondia_软件需求分析说明书.docx`
2. 补充自己项目至少 2 个差异化功能点（写进笔记）

## 六、本节小结（片尾 1 分钟）

- C 端四 Tab + 登录 + 管理后台 + 微服务 API 是主干
- 差异化功能要提前写进需求，避免后期返工
