## 一、学习目标

1. 写出可量化的非功能指标
2. 理解 JWT/HTTPS/密钥外置的安全底线
3. 明确三端兼容基线

## 二、课前准备

- 复习 HTTP/SSE 基本概念

## 三、口播 / 讲解提纲

### 3.1 性能

- 首页加载 < 2s
- AI 首字响应 < 3s（SSE）
- 搜索联想延迟体验指标

### 3.2 安全

- JWT、HTTPS
- 敏感配置外置 Nacos
- 华为 OAuth Secret 仅服务端

### 3.3 兼容

- Flutter 3.x + iOS 12+ / Android 8+
- HarmonyOS NEXT API 12+

### 3.4 可扩展

- 微服务独立扩容
- ES / Redis / MySQL 分离

## 四、屏幕演示步骤

1. 板书四类非功能：性能/安全/兼容/扩展
