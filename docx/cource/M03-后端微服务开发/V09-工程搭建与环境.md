# V09 工程搭建与本地环境

> **所属模块**：M3  ·  **建议时长**：45～60 分钟  ·  **形式**：实操录屏
> **对应大纲**：`Fondia_全栈实战课程大纲.md` → 3.1

## 一、学习目标

1. 完成本地 JDK/Maven/Nacos/MySQL/Redis/ES 环境
2. 导入 jeecg-boot 并能启动 Gateway
3. 掌握推荐启动顺序

## 二、课前准备

- 安装 JDK 17+、Maven、Docker Desktop（可选）
- 克隆 jeecg-boot

## 三、口播 / 讲解提纲

### 3.1 环境清单

- JDK、Maven、IDEA
- Nacos、MySQL、Redis、ES（Docker 可一键）

### 3.2 导入工程

- 识别 parent / module / cloud-start
- 注意 profile：dev/prod

### 3.3 启动顺序

- Nacos → Gateway → user/cuisine/... → system/agent

## 四、屏幕演示步骤

1. 启动 Nacos / MySQL / Redis
2. 配置 application-dev 或 Nacos 配置
3. 按顺序启动 Gateway → user

## 五、课堂实验 / 作业

1. 按启动顺序拉起 Nacos + Gateway + user
2. 浏览器打开 Gateway/doc.html 或健康检查

## 六、本节小结（片尾 1 分钟）

- 先中间件后业务
- 配置优先放 Nacos，本地仅保留引导配置
