# V06 微服务划分与代码模块映射

> **所属模块**：M2  ·  **建议时长**：35～45 分钟  ·  **形式**：讲解 + 看代码目录
> **对应大纲**：`Fondia_全栈实战课程大纲.md` → 2.2

## 一、学习目标

1. 背出 7+ 业务服务职责
2. 能根据 URL 前缀判断落到哪个服务
3. 读懂 gateway_fondia_routes.json

## 二、课前准备

- 打开 `db/gateway_fondia_routes.json`
- IDEA 打开 `jeecg-module-*`

## 三、口播 / 讲解提纲

### 3.1 按服务拆

- jeecg-user：登录/华为 OAuth/资料/反馈
- jeecg-cuisine：菜谱分类 Banner
- jeecg-search：ES 搜索
- jeecg-interaction：收藏点赞评论浏览
- jeecg-support：客服会话（历史与转人工）
- jeecg-member / payment：会员配额与支付
- jeecg-agent：AI 对话（/support/ai/**）

### 3.2 网关实操

- order 越小越优先
- `/support/ai/**` 必须排在 `/support/**` 之前

## 四、屏幕演示步骤

1. 对照表格打开每个 module 目录
2. 逐条读网关路由 JSON

## 五、课堂实验 / 作业

1. 阅读 `gateway_fondia_routes.json`
2. 画出「Path 前缀 → 服务名」表

## 六、本节小结（片尾 1 分钟）

- 路径契约稳定，服务可替换实现（如 AI 迁到 jeecg-agent）
- support 负责客服会话，AI 流式可独立服务
