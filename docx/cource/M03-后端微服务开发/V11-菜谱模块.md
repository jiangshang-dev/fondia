# V11 菜谱模块 jeecg-cuisine

> **所属模块**：M3  ·  **建议时长**：50～70 分钟  ·  **形式**：讲解 + 后台实操
> **对应大纲**：`Fondia_全栈实战课程大纲.md` → 3.3

## 一、学习目标

1. 掌握菜谱/分类/Banner 数据模型
2. 区分管理端与 App 端路径
3. 后台录入菜谱并在 App 可见

## 二、课前准备

- cuisine 服务启动
- 管理后台可登录

## 三、口播 / 讲解提纲

### 3.1 领域模型

- 菜谱、分类树、标签、Banner

### 3.2 双端 API

- 管理：/sys/fd/recipe/**
- App：/cuisine/**

### 3.3 详情结构

- 步骤、食材、视频、营养等扩展字段

## 四、屏幕演示步骤

1. 展示 /sys/fd/recipe/** 与 /cuisine/**
2. 录入「锅包肉」含步骤食材
3. App 分类页刷新验证

## 五、课堂实验 / 作业

1. 后台录入一道完整菜谱（含封面/步骤）
2. App 或接口确认分类列表可见

## 六、本节小结（片尾 1 分钟）

- 管理端写、App 端读，路径分离
- 详情要包含步骤/食材/视频字段
